# EMBER — 월계관의 질주

WebGL 사이드뷰 플랫폼 게임입니다. 세 캐릭터 중 하나를 골라 빛 조각을 수집하고 포털로 장면을 이동합니다.

[배포된 게임 실행](https://laurel-ember-run-1028.souldna9.chatgpt.site/)

## 실행

별도 빌드나 npm 패키지 설치가 필요하지 않습니다. 저장소 폴더에서 정적 서버를 실행하세요.

```sh
python -m http.server 8000 --directory dist
```

브라우저에서 http://localhost:8000 을 엽니다. `file://`로 직접 열면 이미지 정보 JSON을 불러올 수 없으므로 HTTP 서버가 필요합니다.

## 조작

- ← / →: 이동
- Space 또는 ↑: 점프
- ↓: 얇은 발판 아래로 내려가기
- P: 일시정지
- R: 다시 시작
- 상단 버튼: 캐릭터 선택 및 효과음 켜기/끄기

## 구성

- 캐릭터: 황금 갑주 검사, 월계관 요정, 홍련 궁수
- 장면: 01 잿빛 성채 → 02 달빛 숲 → 03 운해 궁성
- 정지 시 정면 대기, 이동 시 측면 달리기
- 포털 접촉 시 장면 전환 및 장면별 수집 상태 유지
- Web Audio 기반 빛 수집 효과음

`dist/game.js`는 렌더링·물리·장면·캐릭터 선택을, `dist/audio.js`는 효과음을 담당합니다. `dist/assets/`에 배경·캐릭터 아틀라스·프레임 정보를 포함합니다. 이미지 자료는 사용자가 제공한 참조와 생성 스프라이트입니다. 게임 내 달리기 모션은 실험용으로, 일부 유사 자세가 반복될 수 있습니다.

## 검사

Node.js로 게임 로직 검사를 실행할 수 있습니다.

```sh
node check-physics.cjs
```

검사는 이동, 점프, 착지, 수집, 효과음 호출, 장면 전환, 캐릭터 선택을 확인하며 WebGL API는 모의 처리합니다. 실제 화면과 음향은 브라우저에서 확인하세요.
